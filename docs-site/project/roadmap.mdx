This is the canonical roadmap. It is directional, not a set of commitments; the
[changelog](/changelog) records what has actually shipped and
[Limitations](/reference/limitations) covers what the current release does not
do.

- **One-line install.** A single command (for example `npx celly`) to install
  and run Celly, without the manual Node, clone, build, and `.env` steps.
- **Image output.** Post images the agent produces — screenshots, diagrams,
  rendered output — into the thread, alongside streamed text.
- **Cloud sandboxes and hosted deployment.** Run projects in cloud sandboxes and
  deploy Celly as a hosted service, so no local host is required.
- **Image and voice input.** Send images and voice messages as prompts, not just
  text and text attachments.
